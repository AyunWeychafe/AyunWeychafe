# Diego Curimán

Industrial engineer in Santiago, Chile. I turn operational processes into software that teams actually use, built by directing AI coding agents (Claude Code, Codex).

## What I've built

- **Purchasing, warehouse and document-control platform** (Google Apps Script + Sheets), used across 10+ engineering contracts. One purchase went from ~26 to ~5 minutes, the monthly PPE count was eliminated, and the team saves ~15 hours a month. No external licenses.
- **Contract planning and control model**: setup per contract went from ~16 hours to ~1–1.5 hours; staffing changes from ~30 to ~3 minutes. 9 contracts, 283 people.
- **Payroll and contract-finance web app** (Next.js, TypeScript, Supabase) to replace an Excel model for payroll, staffing and cash flow across ~12 contracts.
- **AI-assisted inspection planner (pilot)**: drafts an inspection plan from tender documents, detailed engineering and technical standards.
- **Technical lead** for migrating legacy Apps Script apps to Next.js, TypeScript and PostgreSQL; technical audit of 7 apps.

## How I work

Requirements and business rules → solution design → AI coding agents → testing with real users → production support.
